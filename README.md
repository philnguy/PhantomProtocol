# Phantom Protocol – Unreal Engine 5  

A stealth-based gameplay project built in **Unreal Engine 5**, featuring dynamic AI guards, surveillance cameras, noise distraction mechanics, and key collection for progression.  

## 🎮 Features  
- **AI Guards**: Patrol predefined routes and actively track the player once spotted.  
- **Security Cameras**: Rotate and detect players entering their cone of vision.  
- **Key Collection System**: Players must locate keys to unlock restricted areas.  
- **Noise Distraction Mechanic**: Throw objects to lure guards away from their path.  
- **Stealth Gameplay Loop**: Focused on avoiding detection, timing movements, and using strategy to progress.

## 🎯 Learning Outcomes  
This project was created to explore:
- AI design with Behavior Trees and Unreal Perception System
- Stealth mechanics (line-of-sight, vision cones, sound distractions)
- Level design for stealth gameplay flow
- Player interaction systems and progression mechanics

## 🔮 Future Improvements
